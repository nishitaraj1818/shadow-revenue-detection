# Shadow Revenue Detection & Revenue Integrity Analysis

## Project Overview

This project focuses on identifying potential revenue leakage and payment integrity issues using Databricks, PySpark, and data analysis.

The system analyzes revenue-related data to identify:
- Missing Payments
- Orphan Payments
- Price Mismatches
- Shadow Revenue
- Revenue Leakage
- Revenue Integrity

## Technologies Used

- Python
- PySpark
- SQL
- Databricks
- Data Visualization

## Key Metrics

The dashboard provides insights into:

- Expected Revenue
- Order Revenue
- Collected Revenue
- Shadow Revenue
- Revenue Leakage %
- Revenue Integrity Score
- Payment Integrity Issues
- Revenue Leakage Breakdown

## Dashboard

The Databricks dashboard provides a visual overview of revenue performance and potential revenue leakage.
